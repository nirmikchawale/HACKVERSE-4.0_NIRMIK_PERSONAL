STEP 04 / CONTROLLED OPTIONS

Which changes are permitted?

Only explicitly available and confirmed alternatives can appear in a feasible package. A requested resource is not confirmed. No change quantities are preset. Enable only real user-permitted, available, appropriately confirmed options.

Up to 4 options

Each confirmed option is projected if selected; it is not assumed already executed. Resource IDs prevent the same capacity being counted twice. Reducing the target leaves an explicit portion unhandled.
